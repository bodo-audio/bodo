# Commands

Every command registered in `bodo-engine` is documented here: its id, a one-line summary, its parameters and its effects (undoable, destructive, disk, network). MCP generates its tools from the same registry ([ADR 0005](../adr/0005-everything-is-a-command.md)), and AGENTS.md section 7 explains how to add a command.

No commands are registered yet. The registry arrives in milestone M2.
