# File formats

Specifications of Bodo's own file formats:

- [`bodo.md`](bodo.md): `.bodo` projects and `.bodoproj` project folders, decided in [ADR 0007](../adr/0007-project-file-format.md).
- `.bodopack` marketplace packages, decided in [ADR 0010](../adr/0010-marketplace-trust-and-signing.md). The specification is written with the marketplace in milestone M8.
